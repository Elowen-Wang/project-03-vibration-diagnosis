# 盲测准确率视频 · 交付与录屏说明

官网必交 ③：**盲测准确率视频与抗噪报告（20 分）**。抗噪报告见 `../results/noise_robustness.md` / `_round2.md`，本目录为盲测视频与逐段明细。

## 一、目录内容

| 文件 | 作用 |
|---|---|
| `盲测演示.html` | 逐段揭示预测、真实工况与对错，末页显示 12/15 = 80.0%；离线可用，无需联网 |
| `blind_detail.csv` | 第一轮 15 段明细（文件名 / 真实 / 预测 / 对错 / 主频） |
| `blind_detail_round2.csv` | 第二轮 15 段明细（14/15） |
| `盲测准确率演示.mp4` | 11/18 22:24 现场实时录屏（18 MB），末帧停在 12/15 = 80.0% |

演示页的预测由 `tools/make_blind_demo.py` 调用与 `--blind` 相同的最近质心分类器、从 `../results/features.csv` 重算，逐段与 `blind_report.md` 一致，未改动任何预测值。

## 二、两轮盲测

第一轮留每工况 13–15 号，第二轮留 1–3 号，**两轮留出段互不重叠**，第二轮构成对第一轮的独立复核。

| 轮次 | 训练段 | 盲测段 | 准确率 | 明细 |
|---|---|---|---|---|
| 第一轮 | 每工况 1–12 | 13–15 | 80.0%（12/15） | `blind_detail.csv` |
| 第二轮 | 每工况 4–15 | 1–3 | 93.3%（14/15） | `blind_detail_round2.csv` |

两轮训练量相同（每工况 12 段），差异仅来自留出的 3 段不同，说明每类 15 段时测试集选择本身带约 ±7 pp 波动。完整对照见 `../results/盲测两轮对比说明.md`。

**视频不重录**：`盲测准确率演示.mp4` 为 11/18 现场按第一轮数据实时录制的屏幕录像，画面与当时讲解一一对应；替换等于把历史证据换成事后重演。第二轮以明细表与报告留存，两者并行并各自标注轮次，不拼接进同一段视频。

## 三、录屏步骤（Windows，约 5 分钟）

1. 打开演示页：在资源管理器中双击 `盲测演示.html`（默认浏览器即可，无需联网）。
2. 开始录制（三选一）：`Win + Alt + R` 呼出 Xbox Game Bar → 点录制；或「截图工具」→「屏幕录制」；或用手机对着屏幕录像。
3. 播放：点「自动播放全部」，约 17 秒逐条揭示 15 段；需要放慢时改点「揭示下一段」，每段之间说明「这段没参与训练」。
4. 停在结果页：画面需清楚显示 `12 / 15 = 80.0%` 与结论框，停留 3 秒后停录。
5. 停止录制：再按一次 `Win + Alt + R`；Xbox Game Bar 默认存至 `C:\Users\wangy\Videos\Captures`。
6. 归位：复制到本目录并命名为 `盲测准确率演示.mp4`。

## 四、讲解要点

1. 训练集为每工况 1–12 段共 60 段，13–15 段共 15 段完全未参与训练。
2. 特征为 11 维时域 + 频域量，FFT 用 Python 标准库手写，未调用机器学习框架。
3. 12 段判对、3 段判错，错判明细逐条保留在 `blind_detail.csv`。
4. 这是**同批次**盲测；跨日 held-out 是另一回事，README 中已如实区分。

## 五、边界说明

- 留出段为**同一天录制**，不是「换一天重采」的 held-out；被追问时按 README 口径回答。
- 抗噪实验是在已有 WAV 上**人工叠加高斯白噪声**，属仿真压力测试，不等于真实嘈杂环境重采。
