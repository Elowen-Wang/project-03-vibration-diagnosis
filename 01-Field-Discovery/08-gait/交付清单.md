## 三、阈值规则

权威来源为脚本自动生成的 [`../results/08_threshold_rules.md`](../results/08_threshold_rules.md)（`analyze_gait.py` 每次运行重写）；本清单数值为该次运行快照，重跑后以生成文件为准。

```python
if svm_mean < 2.462:            静止      # 合加速度几乎为零
elif svm_mean >= 11.694:        快跑      # 冲击量级远高于慢走与爬楼
elif ratio < 1.393:             上下楼梯   # 垂向力集中在 1× 步频（单脚支撑）
else:                           平地慢走   # 双脚交替，能量落在 2× 步频
```

| 验证方式 | 结果 | 含义 |
|---|---|---|
| 重复分层 5 折（4 种子 × 20 轮 = 120 次） | **88.3%** | 同一次采集内的窗口级可分性，偏乐观 |
| 留一整份源文件 | **63.3%**（30 窗口） | 更接近真实泛化；留出快跑文件 0/7（仅 1 份源文件，训练集无此类） |
| 单次奇偶划分（11/21 旧规则） | 48.0% | 旧判据以垂直幅度分楼梯，两类幅度重叠，原理上不可分 |
| 11/16 三类版本（排除无效快跑） | 50.0% | 原件备份于 [`../results/archive_1116/`](../results/archive_1116/)，保留迭代过程 |
| 阈值标定法对比（11-23） | 均值中点 88.3% / 63.3% 为最优 | 中位数中点 85.8 / 63.3、分位数中点 81.7 / 56.7、训练集最优切分 88.3 / 60.0（跨文件下降，判为过拟合）；四法保留在 `calibrate(method=...)` |

两个指标并列报出，不只报较高者。官网第一阶段未要求高准确率，把适用边界讲清（每类仅 1 次采集）比单报一个数字更重要。
