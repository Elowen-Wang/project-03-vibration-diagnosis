## 三、阈值规则

[`../results/08_threshold_rules.md`](../results/08_threshold_rules.md) —— 可解释规则、自动标定阈值、特征定义、**两层交叉验证**、活动段裁剪依据、诚实解读，一次写全。

规则本体（阈值由训练窗口自动标定，**实际数值以脚本生成结果为准**，见下方「阈值以哪份文件为准」）：

```python
if svm_mean < 2.462:            静止      # 合加速度几乎为零
elif svm_mean >= 11.694:        快跑      # 冲击量级远高于慢走与爬楼
elif ratio < 1.393:             上下楼梯   # 垂向力集中在 1× 步频（单脚支撑）
else:                           平地慢走   # 双脚交替，能量落在 2× 步频
```

> **阈值以哪份文件为准**：唯一权威来源是脚本自动生成的
> [`../results/08_threshold_rules.md`](../results/08_threshold_rules.md)（`analyze_gait.py` 每次运行都会重写）。
> 本清单里的阈值是**该次运行的快照**，若重跑后数据或标定结果有变，以生成文件为准。
> 2026-11-23 最新一次生成值：`svm_static=2.462`、`svm_run=11.694`、`ratio=1.393`。

| 验证方式 | 结果 | 含义 |
|---|---|---|
| 重复分层 5 折交叉验证（4 种子 × 20 轮 = 120 次） | **88.3%** | 同一次采集内的窗口级可分性（**偏乐观**） |
| 留一整份源文件 | **63.3%**（30 窗口） | 更接近真实泛化；留出快跑文件时 0/7，因快跑仅 1 份源文件、训练集无此类 |
| 单次奇偶划分（11/21 旧规则） | 48.0% | 旧判据用垂直幅度分楼梯，两类幅度完全重叠，原理上不可分 |
| 11/16 的 3 类版本（排除无效快跑） | 50.0% | 原件备份在 [`../results/archive_1116/`](../results/archive_1116/)，便于展示迭代过程 |
| 阈值标定法对比（11-23） | 均值中点 88.3% / 63.3% 最优 | 中位数中点 85.8 / 63.3、分位数中点 81.7 / 56.7、训练集最优切分 88.3 / 60.0（跨文件下降，判为过拟合）；四法均保留在 `calibrate(method=...)` |

**两个数字都写进报告，不只报好看的那个。** 官网第一阶段未要求高准确率；
把适用边界讲清楚（每类仅 1 次采集）比报一个漂亮数字更重要。
