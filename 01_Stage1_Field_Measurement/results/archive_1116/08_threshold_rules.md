## 特征定义

| 特征 | 物理含义 |
|---|---|
| `svm_mean` | 合加速度均值，区分静止与运动 |
| `svm_std` | 合加速度波动强度 |
| `az_range` | 垂直轴 95–5 分位幅度，楼梯冲击更大 |
| `dominant_hz` | 合加速度主频 ≈ 步频 |
| `zcr` / `centroid` | 过零率 / 频谱质心，辅助表征动作剧烈程度 |

## 可解释规则

```python
if svm_std < 1.370:              静止     # 合加速度几乎不波动
# 快跑分支暂禁用：该类有效样本待重采，不拿默认值硬判
elif az_range >= 8.16:           上下楼梯 # 垂直冲击更大
else:                                   平地慢走
```

当前阈值由**训练窗口自动标定**（取两类均值中点）：`svm_std=1.370`、`dominant_hz=禁用（样本缺失）`、`az_range=8.16`；测试窗口完全不参与标定。

## 当前结果的诚实解读

- 本表的准确率是**流程验证值，不是最终结论**：4 类里「快跑」有效样本待重采，当前只剩 3 类。
- 官网对第一阶段要的是「原始 CSV + 波形图 + 可解释阈值规则 + 现场证据」，并未要求高准确率；把分不开的原因讲清楚，比报一个挑出来的漂亮数字更重要。
- 平地慢走与上下楼梯的 `az_range`、`svm_std` 范围高度重叠，说明手机佩戴方式与行走速度带来的幅度差异，已经盖过了动作类型本身的差异。
- 下一步：① 重采快跑（≥12 s 连续、中途不要暂停）；② 每类补到 3 次以估计类内波动；③ 改用主频 / 频谱质心等相对特征为主判据；④ 全程固定同一手机位置并写进日志。
