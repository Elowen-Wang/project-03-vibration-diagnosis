## 特征定义

| 特征 | 物理含义 |
|---|---|
| `svm_mean` | 合加速度均值，区分静止与运动 |
| `svm_std` | 合加速度波动强度 |
| `az_range` | 垂直轴 95–5 分位幅度，楼梯冲击更大 |
| `dominant_hz` | 合加速度主频 ≈ 步频 |
| `zcr` / `centroid` | 过零率 / 频谱质心，辅助表征动作剧烈程度 |

## 可解释规则

```python
if svm_std < 0.359:              静止     # 合加速度几乎不波动
elif dominant_hz >= 2.54:    快跑     # 步频显著更高
elif az_range >= 3.05:           上下楼梯 # 垂直冲击更大
else:                                   平地慢走
```

当前阈值由**训练窗口自动标定**（取两类均值中点）：`svm_std=0.359`、`dominant_hz=2.54`、`az_range=3.05`；测试窗口完全不参与标定。
