## 特征定义

| 特征 | 物理含义 |
|---|---|
| `svm_mean` | 合加速度均值，区分静止与运动 |
| `svm_std` | 合加速度波动强度 |
| `az_range` | 垂直轴 95–5 分位幅度，楼梯冲击更大 |
| `dominant_hz` | 合加速度主频 ≈ 步频 |
| `zcr` / `centroid` | 过零率 / 频谱质心，辅助表征动作剧烈程度 |

## 可解释规则

```python
if svm_std < 1.370:              静止     # 合加速度几乎不波动
elif dominant_hz >= 3.57:    快跑     # 步频显著更高
elif az_range >= 8.16:           上下楼梯 # 垂直冲击更大
else:                                   平地慢走
```

当前阈值由**训练窗口自动标定**（取两类均值中点）：`svm_std=1.370`、`dominant_hz=3.57`、`az_range=8.16`；测试窗口完全不参与标定。

- 三个阈值由脚本从训练窗口自动标定（两类均值中点），换真实数据后自动更新，不用手改代码。

## 当前结果的诚实解读

- 4 类的**原始 CSV、波形图、可解释阈值规则已齐**，满足官网形式要求；快跑组已于 11-19 重采（31.98 s、无暂停、RMS 17.31），旧版 3.88 s 无效样本已保留作对照，**没有删除、没有修改、没有补造数据**。
- 留出集 48.0%：快跑重采后有效窗口充足，阈值可可靠标定；当前主要混淆是平地慢走 ↔ 上下楼梯的 `az_range` / `svm_std` 范围高度重叠，手机佩戴方式与行走速度带来的幅度差异盖过了动作类型本身的差异。
- **设备不一致需如实说明**：快跑重采用 iPhone18,3（iOS 26.1），其余 4 组为 iPhone17,2（iOS 27.0）。幅度类特征（svm_mean / az_range）存在机型系统差异，跨组比较时按设备分列，不混写成同一台。
- 官网对第一阶段要的是「原始 CSV + 波形图 + 可解释阈值规则 + 现场证据」，并未要求高准确率；把分不开的原因讲清楚，比报一个挑出来的漂亮数字更重要。
- 其余改进：每类补到 3 次以估计类内波动；改用主频 / 频谱质心等相对特征为主判据；尽量固定同一手机位置并写进日志。
