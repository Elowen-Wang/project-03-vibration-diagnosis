## 特征定义

| 特征 | 物理含义 |
|---|---|
| `svm_mean` | 合加速度均值，区分静止与运动 |
| `svm_std` | 合加速度波动强度 |
| `az_range` | 垂直轴 95–5 分位幅度，楼梯冲击更大 |
| `dominant_hz` | 合加速度主频 ≈ 步频 |
| `zcr` / `centroid` | 过零率 / 频谱质心，辅助表征动作剧烈程度 |

## 可解释规则

```python
if svm_std < 0.639:              静止     # 合加速度几乎不波动
elif dominant_hz >= 2.25:    快跑     # 步频显著更高
elif az_range >= 8.82:           上下楼梯 # 垂直冲击更大
else:                                   平地慢走
```

当前阈值由**训练窗口自动标定**（取两类均值中点）：`svm_std=0.639`、`dominant_hz=2.25`、`az_range=8.82`；测试窗口完全不参与标定。

## 阈值重标定说明

- 三个阈值由脚本从训练窗口自动标定（两类均值中点），换真实数据后自动更新，不用手改代码。
- 若准确率不理想：先看上表哪两类特征范围重叠，考虑延长窗口或更多依赖主频类稳健特征。
- 手机固定位置（口袋 / 手持 / 臂包）会显著改变幅度类特征，全程保持一致并在 README 写明。
- 主频比幅度更稳健：不同人、不同鞋、不同手机位置下，步频变化小于幅度变化。

## 当前结果的诚实解读

- 4 类的**原始 CSV、波形图、可解释阈值规则已齐**，满足官网形式要求；但「快跑」组依据《课题08核对报告》判定为无效采集，本次只是如实纳入并显著标注，**没有删除、没有修改、没有补造数据**。
- 留出集 52.6% 偏低的主因有两条：① 快跑只有 1 个有效窗口，阈值几乎无法可靠标定；② 平地慢走与上下楼梯的 `az_range` / `svm_std` 范围高度重叠，手机佩戴方式与行走速度带来的幅度差异盖过了动作类型本身的差异。
- 官网对第一阶段要的是「原始 CSV + 波形图 + 可解释阈值规则 + 现场证据」，并未要求高准确率；把分不开的原因讲清楚，比报一个挑出来的漂亮数字更重要。
