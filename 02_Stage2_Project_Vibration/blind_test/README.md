## 二、录屏步骤（Windows，约 5 分钟）

1. **打开演示页**：在文件资源管理器里进入本目录，双击 `盲测演示.html`（默认浏览器打开即可，**不需要联网**）。
2. **开始录制**（三选一，哪个能用用哪个）：
   - 按 `Win + Alt + R` 呼出 Xbox Game Bar → 点红色圆点开始录制；
   - 或打开「Windows 截图工具」（开始菜单搜 `截图`）→ 选「屏幕录制」→ 点开始；
   - 或干脆用**手机对着电脑屏幕录像**，官网只要视频证据，不苛求录制方式。
3. **播放**：在网页上点「**自动播放全部**」，等约 17 秒，15 段逐条揭示；
   想讲得慢一点就改点「揭示下一段」，每段之间口头说明「这段没参与训练」。
4. **停在结果页**：最后画面要清楚显示 `12 / 15 = 80.0%` 和绿色结论框，停留 3 秒再停录。
5. **停止录制**：再按一次 `Win + Alt + R`（或用录制工具栏的停止按钮）。
   Xbox Game Bar 默认存到 `C:\Users\wangy\Videos\Captures`。
6. **放进仓库**：把录好的 mp4 复制到本目录，改名为 `盲测准确率演示.mp4`。

## 三、视频里最好顺口说的 4 句话

1. 「训练集是每工况 1–12 段，共 60 段；13–15 段完全没参与训练，共 15 段。」
2. 「特征是 11 维时域 + 频域量，FFT 用 Python 标准库手写，没有调机器学习框架。」
3. 「12 段判对、3 段判错，判错的明细我没删，在 `blind_detail.csv` 里逐条留着。」
4. 「这是**同批次**盲测；跨日 held-out 是另一回事，我在 README 里如实区分了。」

## 四、边界说明（一定要讲）

- 这是**同一天录制**的 13–15 段，不是「换一天重采」的 held-out；官网若追问，按 README 的说法答。
- 抗噪实验是在已有 WAV 上**人工叠加高斯白噪声**，属仿真压力测试，不等于真实嘈杂环境重采。
