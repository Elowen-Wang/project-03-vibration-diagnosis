## 边界说明（面试主动讲，别等被问出来）

- **同批次盲测 ≠ 跨日 held-out**：13–15 段是同一天录的，只是没参与训练；`--heldout` 需要另一天重采 15 段，目前目录 `blind_test/blind_*.wav` 为空，README 里已如实写。
- **抗噪是仿真加噪**：在已有 WAV 上叠高斯白噪声，不等于真实嘈杂环境重采。
- **加速度通道未完成**：官网目标提到「麦克风与加速度计」，当前 75 段只有声学通道；`--accel` 已支持读 `accel_raw/*.csv`，若今晚补采即自动出 `results/accel_features.csv`。若来不及，报告中如实写「受设备/时间限制，采用声学单通道完成分类，无法验证声振融合，但 FFT 与分类方法一致」，**不编造数据**。
- **MP3 转 WAV 只是换容器**，不恢复已丢失的高频，不写成「转换为无损音质」。

## 复现命令（仓库根目录）

```bat
python 02_Stage2_Project_Vibration\analyze_real_wav.py --all
python tools\make_blind_demo.py
```

`--all` = extract / classify / blind / noise / heldout / check 全跑一遍；单项可换成 `--extract`、`--classify`、`--blind`、`--noise`、`--accel`、`--check`。
