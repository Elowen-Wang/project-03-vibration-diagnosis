## 边界说明（主动交代，不等追问）

- **同批次盲测 ≠ 跨日 held-out**：13–15 段是同一天录的，只是没参与训练；跨日 held-out 未采集（0/15），如实列为局限，不拿同批次盲测冒充。
- **抗噪是仿真加噪**：在已有 WAV 上叠高斯白噪声，不等于真实嘈杂环境重采。
- **加速度通道未采**：官网目标提到「麦克风与加速度计」，当前 75 段只有声学通道。已量化这条缺失的真实边界——100 Hz 以下仅占 1.5% 能量，1× 转频（100–155 Hz）仍在可观测区间，缺的是低频结构振动；包络解调用声学信号做过替代试验，无增益。分类以声学单通道完成，未验证声振融合增益，**不编造数据**（`results/acoustic_band_limits.md`、`envelope_experiment.md`）。
- **MP3 转 WAV 只是换容器**，不恢复已丢失的高频，不写成「转换为无损音质」。

## 复现命令（仓库根目录）

```bat
python 02_Stage2_Project_Vibration\analyze_real_wav.py --all
python 02_Stage2_Project_Vibration\analyze_acoustic_limits.py --all
python tools\make_blind_demo.py
```

`--all` = extract / classify / blind / noise / heldout / check 全跑一遍；单项可换成 `--extract`、`--classify`、`--blind`、`--noise`、`--accel`、`--check`。
`analyze_acoustic_limits.py` 约 7 分钟（48 kHz 全频带 FFT + 包络解调）；只改图形版式时用 `--charts` / `--envcharts`。
