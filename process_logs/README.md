## 写日志的三条规矩

1. 没做完就如实留空，写清卡在哪、次日如何补；不补写未发生的事。
2. 异常数据（11-05 的 7 dB、11-16 快跑无效组）保留原值 + 标注原因 + 安排重测，不删不改。
3. 每天至少一次 commit，说明带日期与当天实际动作，不写 "update"。
