## 写日志的三条规矩

1. 没做完就如实留空，写清楚卡在哪、明天怎么补；**不要补写没发生的事**。
2. 异常数据（比如 11-05 的 7 dB、11-16 的快跑无效组）保留原值 + 标注原因 + 安排重测，不删不改。
3. 每天至少一次 commit，说明里带日期和当天实际动作，不写 "update"。
